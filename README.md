# HTTP Proxy Router

> Servidor proxy reverso com roteamento condicional de tráfego, classificação de ameaças e telemetria em tempo real. Em produção em VPS Oracle Cloud.

---

## Visao Geral

O **HTTP Proxy Router** é um sistema de proxy reverso de alta performance desenvolvido para roteamento condicional de tráfego HTTP/HTTPS, filtragem de requisições, detecção de ameaças e telemetria em tempo real, rodando em produção em VPS Oracle Cloud.

---

## Funcionalidades

| Feature | Descricao |
|---|---|
| **Roteamento Condicional** | Direcionamento inteligente de tráfego baseado em rotas, headers e parâmetros |
| **Classificação de Ameaças** | Detecção e bloqueio preventivo de requisições maliciosas e scanners |
| **Telemetria em Tempo Real** | Monitoramento de latência, status codes e volumetria de requisições |
| **Alta Performance** | Arquitetura leve e otimizada para ambiente cloud |

---

## Stack Tecnologica

- **Plataforma:** Node.js / TypeScript
- **Infraestrutura:** VPS Oracle Cloud Linux
- **Monitoramento:** Telemetria integrada
